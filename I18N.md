# Français / anglais — un seul site, une seule source de contenu

Pages actives : `index.html`, `assistance.html`, `confidentialite.html`.
Les versions anglaises statiques se trouvent dans `en/`. Les photos, les logos,
les captures et les scripts d’animation restent communs. Les anciens fichiers
archivés du dépôt ne sont ni supprimés ni promus en nouvelles pages du site.
Il n’existe pas de page Actualités autonome dans la navigation actuelle.

## Liens et choix de langue

- Français explicite : https://michelpalmer256-afk.github.io/beaver4x4ai/?lang=fr
- Anglais : https://michelpalmer256-afk.github.io/beaver4x4ai/en/
- `?lang=en` et `?lang=fr` fonctionnent aussi sur les trois pages actives.
- Priorité : paramètre explicite, chemin anglais partagé, choix mémorisé,
  puis navigateur (`fr*` → français, toutes les autres langues → anglais).
- La première détection et les choix manuels sont conservés dans
  `localStorage`, sous `beaver-language`. Si le stockage est indisponible,
  les liens continuent de fonctionner ; le contexte français est transmis
  dans les liens internes. Le changement conserve le fragment de section.

`language.js` détermine uniquement la langue et les adresses. Il n’appelle aucun
service de traduction et ne remplace pas le contenu à chaque visite. Les pages
anglaises contiennent déjà leurs traductions, y compris sans JavaScript.

La signature de marque « PRÉPARE · EXPLORE · PARTAGE » et les logos restent en
français. L’adaptation « Prepare · Explore · Share » est utilisée dans les textes
anglais. Les captures officielles restent celles de l’app en français : la version
anglaise du site l’indique, sans créer de fausses captures ni modifier les images.

## Modifier les contenus

1. Modifier les pages françaises sources et ajouter les traductions naturelles
   dans `locales/en.json` (textes, textes alternatifs et libellés accessibles).
2. Exécuter `python3 scripts/build_i18n.py` depuis le checkout existant.
3. Exécuter `python3 scripts/build_i18n.py --check`.
4. Inclure les fichiers générés `en/`, les métadonnées françaises et `sitemap.xml`
   dans le même commit. Ne pas modifier les fichiers générés manuellement.

Le générateur utilise uniquement la bibliothèque standard Python. Il refuse un
texte nouveau sans traduction, sauf les marques, noms propres et symboles
explicitement conservés. Il génère aussi les titres/descriptions, les balises
`lang`, `canonical`, `hreflang`, Open Graph et le sitemap des six adresses.
Les chemins d’images et l’allumage fonctionnent depuis les deux langues.

## Validation

Lancer le serveur statique depuis `/workspace/beaver4x4ai` :

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Puis :

```sh
node --check language.js
node --check quality.js
python3 scripts/build_i18n.py --check
python3 tests/i18n_check.py
python3 tests/browser_check.py
python3 tests/intro_check.py
BASE_URL=http://127.0.0.1:8000/en/ SITE_LANGUAGE=en python3 tests/intro_check.py
```

Tests Chromium : choix navigateur FR/EN/NL/DE, stockage bloqué, priorité des liens,
choix mémorisé, ancres, images locales, textes et accessibilité, SEO, responsive
320/390/768/1440 pixels, animations dans les deux langues et mouvement réduit.
Les contrôles ne remplacent pas un test sur Safari Mac/iPhone réel.

Les contenus d’assistance et de confidentialité actuellement publiés restent
provisoires. Leur traduction ne crée ni politique officielle, ni coordonnées,
ni nouveaux engagements juridiques. Ils doivent être complétés avant lancement.
