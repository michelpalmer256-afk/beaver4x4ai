BEAVER4X4 AI — SITE V2

1. Décompresser le ZIP sur le Mac.
2. Dans le dépôt GitHub beaver4x4ai, choisir Add file > Upload files.
3. Glisser le fichier index.html (pas le ZIP), puis Commit changes.
4. Conserver assistance.html et confidentialite.html déjà présents.
5. Attendre 1 à 3 minutes puis actualiser le site GitHub Pages.

Cette version n'utilise qu'un seul fichier index.html (CSS et JS intégrés).
Les photographies sont chargées depuis Unsplash et nécessitent une connexion Internet.
Le mockup Copilote est une démonstration visuelle, pas un chatbot fonctionnel.
